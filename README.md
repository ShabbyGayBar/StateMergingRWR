This is a standalone mod combining the [States Merging Mod](https://github.com/ShabbyGayBar/StateMerging) and [Explorable Real-World Resources Mod](https://steamcommunity.com/sharedfiles/filedetails/?id=3459869359).

Enable **only this combined mod**, **Do NOT ENABLE** either original mod. Start a **new campaign**; existing saves from vanilla or either source mod are unsupported. Other mods replacing the same maps, histories, or scripts can conflict.

## Description

This mod combines multiple states in the [Explorable Real-World Resources Mod](https://steamcommunity.com/sharedfiles/filedetails/?id=3459869359) together while keeping the overall pop & buildings unchanged.

Barracks & naval base cap as well as taxation which were reduced due to less number of states will be compensated (partially) by granting state buffs.

Speaking of buffs, they were given according to how many vanilla states they merged, except several ultra-minor states that don't deserve being a state at all (no offense).

Merged states WILL LOSE THEIR CITY & BUILDING MODELS.

Merged states WILL LOSE THEIR STATE ID, which may cause problems with certain journal entries and such. please report issues when you encounter them.

- Subscribe to the mod on [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3833507054).
or
- Download the mod from [Paradox Mods](https://mods.paradoxplaza.com/mods/166222/Any).
or
- Download the mod zip file from the [release page](https://github.com/ShabbyGayBar/StateMergingRWR/releases) and extract it to your Victoria 3 mod folder (typically located at `Documents\Paradox Interactive\Victoria 3\mod`).
